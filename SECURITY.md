# Security policy

## Supported versions

Only the latest released version gets security fixes. The extension updates automatically in Azure DevOps organizations that installed it from the Marketplace.

## Reporting a vulnerability

Please don't report security issues in public issues or pull requests.

Report them privately through GitHub: **Security › Report a vulnerability** on this repository ([private vulnerability reporting](https://github.com/axiansinfoma/ado-releases/security/advisories/new)). Include what you found, how to reproduce it, and the affected version.

We acknowledge reports within five working days and keep you informed until the issue is fixed. We credit reporters in the advisory unless you prefer otherwise.

## Scope

- The Releases page, the pipeline task, the CLI and the core library in this repository.
- The extension's access: the scope **Code (read and write)** and the permissions described in the [README](https://github.com/axiansinfoma/ado-releases#permissions).

Vulnerabilities in Azure DevOps itself go to the [Microsoft Security Response Center](https://msrc.microsoft.com/).
